# Color-Screen documentation

Color-Screen reconstructs early additive colour-screen photographs from digitised scans. **Color-Screen 2.0** uses the maintained Qt GUI and human-readable JSON documents. The version 2.0 series is still in development; download the tested rolling prerelease from [the current release page](https://github.com/janhubicka/Color-Screen/releases/tag/current).

## Color-Screen 2.0 — current documentation

- **[User manual](Color-Screen-2.0-User-Manual)** — installing, opening scans, capture and screen workflow, registration, sharpening, colour, export, preferences and recovery
- **[Parameter format](Color-Screen-2.0-Parameter-Format)** — native `.cspar` processing documents (UTF-8 JSON schema 3)
- [Complete parameter field reference](Color-Screen-2.0-Parameter-Fields) — all schema-3 JSON fields, types, variants and structural constraints
- **[Stitch project format](Color-Screen-2.0-Project-Format)** — native `.csprj` projects (UTF-8 JSON schema 2), legacy project conversion and tile references
- [Source repository and build instructions](https://github.com/janhubicka/Color-Screen)

### Documentation for Color-Screen 1.0

The original Java/GTK GUI, historical command-line examples and old rendering instructions have been preserved in the **[historical 1.0 documentation](Color-Screen-1.0-Documentation)**. The [original wiki Home page](Color-Screen-1.0-Original-Home) is archived there. Existing historical article links remain valid.

**Version distinction:** `.cspar` and JSON `.csprj` document the 2.0 development interface; original keyword-text `.par` and version-1 stitching projects are still readable for migration.
